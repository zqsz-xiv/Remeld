# Remeld

Remeld is a solver for finding best in slot gearsets for Final Fantasy XIV's Black Mage.

This is a port of Itu's solver from Google Sheets AppScript to Javascript.

## Instructions
Download all .js files and open "RunBisSolve.js" to set parameters before running with node from a terminal of your choice.

## Known Issues:
- Damage formula rounding means that simulated damage will not be perfectly consistent with the game, nor other gear solvers.
